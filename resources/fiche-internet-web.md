# Fiche mémo — Internet & Web

## Internet
Internet est un réseau mondial de réseaux interconnectés. Les appareils communiquent en échangeant des paquets de données, acheminés par des routeurs.

## Web
Le Web est un service qui fonctionne sur Internet. Il permet de consulter des pages et ressources reliées par des liens hypertextes.

## À retenir
- Un navigateur demande des ressources aux serveurs web.
- Une URL indique l’adresse d’une ressource.
- HTTP organise les échanges ; HTTPS ajoute le chiffrement TLS.
- Le DNS associe les noms de domaine aux adresses IP.

## Petit défi
Explique en une phrase pourquoi Internet et le Web ne sont pas synonymes.
